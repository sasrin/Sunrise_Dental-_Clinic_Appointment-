How to Use the Sunrise Dental Clinic Management System

1. How to Login

  1. Open the application in your web browser
  2. Enter your username in the "Username" field
  3. Enter your password in the "Password" field
  4. Click the "Login" button
  5. If credentials are correct, you will be redirected to the dashboard
  6. If credentials are incorrect, an error message will be displayed

2. How to Register a New Appointment

  1. From the dashboard, click "Register New Appointment"
  2. Fill in all required fields:
    • Appointment Number (must be unique)
    • Patient Name
    • Address
    • Contact Number (10 digits)
    • Dentist Name
    • Treatment Type (select from dropdown)
    • Appointment Date
    • Appointment Time
  3. Click "Register Appointment" button
  4. If successful, a success message will appear
  5. If there are errors, an error message will guide you

3. How to Search for an Appointment

  1. From the dashboard, click "Search Appointment"
  2. Enter the appointment number in the search field
  3. Click the "Search" button
  4. If found, the appointment details will be displayed
  5. If not found, "Appointment not found" message will appear

4. How to Display Appointment Details

  1. Use the Search Appointment function
  2. Enter the appointment number
  3. Click Search
  4. All appointment details will be displayed including:
    • Appointment Number
    • Patient Name
    • Address
    • Contact Number
    • Dentist Name
    • Treatment Type
    • Appointment Date
    • Appointment Time

5. How to Calculate a Bill

  1. From the dashboard, click "Calculate & Print Bill"
  2. Enter the appointment number
  3. Click "Calculate Bill" button
  4. The system will retrieve the appointment and calculate:
    • Treatment Cost (based on treatment type)
    • Consultation Fee (fixed amount)
    • Total Amount (Treatment Cost + Consultation Fee)
  5. The bill summary will be displayed

6. How to Print the Bill

  1. After calculating the bill, click "Print Bill" button
  2. You will be redirected to the receipt page
  3. Click "Print Bill" button on the receipt page
  4. Your browser's print dialog will open
  5. Select your printer and click Print
  6. The receipt will print in a professional format

7. How to Logout / Exit the System

  1. From any page, navigate to the dashboard
  2. Click the "Logout" button at the bottom of the dashboard
  3. Your session will be terminated
  4. You will be redirected to the login page
  5. You must login again to access the system

Important Notes:

  • Always keep your password secure and do not share it
  • Appointment numbers must be unique for each appointment
  • Contact numbers must be 10 digits
  • All fields marked with * are required
  • If you encounter any issues, contact your system administrator
